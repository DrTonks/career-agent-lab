# 产品与研究资料

核对日期：2026年11月6日。

| 资料 | 采用的事实与设计参照 |
|---|---|
| [Mem0 Update Memory Operation](https://docs.mem0.ai/core-concepts/memory-operations/update) | 按记忆ID更新内容或元数据，再检查更新后的检索结果。 |
| [Letta Memory](https://docs.letta.com/agent-sdk/memory) | 持久记忆、共享记忆仓库及后台整理；其整理可由步数或压缩事件触发。 |
| [Claude Memory stores](https://platform.claude.com/docs/en/managed-agents/memory) | 跨会话记忆、内容哈希前置条件、不可变版本与审计。 |
| [Claude Dreams](https://platform.claude.com/docs/en/managed-agents/dreams) | 根据已有记忆和历史会话综合整理，形成新的输出记忆库。 |
| [StateGraph](https://arxiv.org/abs/2611.02912) | 依赖感知的长期记忆修订、反事实依赖验证与选择性传播。 |
| [COUNTERMEM](https://arxiv.org/abs/2609.31874) | 通过可执行世界模型验证替代动作，并保存反事实记忆。 |
| [CRITIC](https://arxiv.org/abs/2305.11738) | 借助外部工具反馈进行检查与纠错。 |

本方案的设计切口是已生成建议的条件失效：将来源允许的反例组织成绑定目标版本和角色的取证任务，由真实材料支持后续局部提交。比较围绕各产品公开的主要机制与本项目重心展开，适合在现有存储、检索和记忆管理能力上组合实现。
