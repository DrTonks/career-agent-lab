# 画像评分规范 v2（独立设计，尚未实证校准）

统一维度：professionalSkill 专业技能；certificate 证书；innovation 创新；internalMotivation 内驱；learning 学习；stressTolerance 抗压；communication 沟通；internship 企业实习经历；language 语言；leadership 领导协作；adaptability 适应；execution 执行。

## 事实、缺失与分数

评分是用户材料所支持的描述性估计，不是心理测量、录用概率或独立背景核查。null 表示缺乏充分证据；0 仅用于有明确原文支持的未具备/未发生状态，basis 必须是 explicit_absence。没有写证书或实习不能记0。正分 basis 使用 behavior 或 credential，不能用 explicit_absence。同一维度的同一来源/引文不得重复计权。

internship 专指企业实习经历，不再标作泛化的“实践能力”。明确“无企业实习”可以是0，但校园项目仍可支持专业技能、执行和其他有行为证据的维度；不得推出整体实践能力为0。个人项目、课程设计不是企业实习，也不能反过来补造实习经历。原数据的同名能力字段可能使用不同口径，没有校准前不能作直接数值匹配。

## 每个维度须先满足的证据条件

| 维度 | 可用证据 | 不能据此推断 |
| --- | --- | --- |
| professionalSkill | 具体技术任务、本人操作及产物 | 仅列工具名就精通 |
| certificate | 证书名称、级别、取得状态 | 培训经历等于取得证书 |
| innovation | 新方法、与原方法的差异及验证 | 完成普通项目即创新 |
| internalMotivation | 自主目标、持续行动和选择理由 | “独立完成”即持续内驱 |
| learning | 学习过程、反馈修正或迁移实例 | 使用某技术即学习能力强 |
| stressTolerance | 压力情境、应对行为和结果 | 项目按期完成即抗压 |
| communication | 信息表达、需求澄清、协调行为 | 一起做项目即领导 |
| internship | 明确企业实习身份、职责与产出 | 校园项目等于企业实习 |
| language | 具体语言使用或考试证据 | 技术栈英文名称即外语能力 |
| leadership | 组织、分工、决策、反馈和团队结果 | 团队成员身份即领导 |
| adaptability | 情境变更、调整行为及结果 | 修复普通缺陷即适应能力 |
| execution | 具体任务、本人行动及完成结果 | 意愿或计划即已完成 |

满足维度证据条件后才选择锚点等级。锚点0–4对应0/25/50/75/100：1为有限接触/参与且有具体依据；2为具体实践、能说明个人职责但结果或独立性有限；3为独立完成较复杂任务，过程、产物、结果及限制可定位；4为多场景持续表现和可核对影响。证书/语言须按其具体资质解释，不能机械套项目复杂度；当前没有外部资格等级到分数的校准表，证据不足时保留事实、分数null并追问。

不同观察按 confidence 加权平均，由 profile_score 计算；confidence 是描述性权重，不是统计概率。逐字引用校验只能证明原文存在，不能证明维度判断正确。规则文本、岗位要求、系统生成报告不能作为个人得分的事实来源。不得将同一项目的泛化形容词铺到多个软维度。

优先追问本人职责、产物、困难与处理、效果衡量和时间范围。不索要与职业任务无关的敏感身份信息。此版本没有原项目校准集，不假设与岗位画像数值完全对齐；正式评测前在独立开发集明确校准并冻结，不能用测试结果反向调权。
