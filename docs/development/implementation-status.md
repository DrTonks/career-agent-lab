# 实现状态与使用边界

当前版本适合作为可运行的CLI智能体核心与开发预览，完整业务验收尚未通过。总控与四专家、领域工具、持久化和记忆已实现；现有400项确定性工程检查通过，回放与故障检查不等于真实模型语义正确。

| 模块 | 已实现 | 当前边界 |
| --- | --- | --- |
| 总控与专家 | DAG计划、按任务路由、独立步骤历史、工具及知识权限、产物交接 | 真实批次未触发主动协作工具，不能据此宣称自主讨论已验证 |
| 动态协调 | 分类重试、补证请求、任务内依赖失效与局部保留 | 跨用户输入按版本保守重验；长程语义仍需完善 |
| 画像/匹配/路径/报告 | 12维描述性画像、硬条件检查、BM25/本地向量RRF、有界图路径、版本化报告 | 画像未经心理测量校准；数据未知不等于符合岗位要求 |
| 上下文 | 原始输入分页、工具对压缩、检索工作状态、按身份重读 | 摘要可能丢失细节；多轮事实与引用口径仍存在问题 |
| 记忆 | 用户/领域授权、来源与版本、审批、纠正、撤回、到期及遗忘 | 独立归档不随运行库遗忘删除；展示的审批说明仍需语义核查 |
| 恢复 | SQLite WAL、checkpoint、工具缓存、租约、幂等回执和响应恢复 | 有限故障窗口已测，外部请求结果丢失时不能承诺恰好执行一次 |
| 模型与接口 | OpenAI兼容流、工具调用、usage、超时、有限重试；JSON CLI | HTTP服务、生产鉴权、文件解析、OCR和视觉输入未包含 |
| 最终核验 | 来源绑定、计算范围核对、分段审阅、有界修订与未发布状态 | 存在数量/语义范围误拦；有内部产物不代表已交付最终答复 |

## 优先改进

1. 修复已确认的数量范围误拦，明确可靠部分的交付规则，保留真正无依据内容的拦截。
2. 回归用户更正、当前有效事实、审批状态和来源轮次的一致性。
3. 发布时验证干净安装与CLI操作；作为服务部署时另建鉴权、请求管理与接入层。

当前没有证据要求推倒总控与四专家架构。源码公开与生产服务上线是不同交付范围；展示demo也可在独立前后端中使用明确标注的场景数据，不依赖完整运行时或模型服务。

## 数据与验证

公开数据为24条合成岗位、6个类别、5条图边和领域规则。导入数据、索引、模型缓存、运行记录和评审原文均留本地，不随Git提交。详细机制见[架构地图](../README.md)，使用方法见[运行指南](../architecture/runtime-usage.md)，测试方法见[开发说明](contributing.md)，最终对照统计见[评估结果](../evaluation/results.md)。
