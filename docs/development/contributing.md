# 开发与验证

需要Node.js 24或更高版本，使用锁文件安装依赖。

~~~powershell
npm ci
npm run check
npm run format:check
npm run public:check
~~~

测试使用合成数据、明确回放和真实本地进程故障，不需要模型API凭证。回放验证的是权限、协议、状态和恢复，不是模型回答质量。测试目录见[地图](../../tests/README.md)。

修改机制应覆盖相应不变量：专家身份与来源权限、工具调用和结果配对、过期产物失效、审批版本与幂等、进程退出后的持久状态、失败与未知用量。文档与低影响改动不需要机械添加测试。真实模型调用需要显式使用live模式，不能混入默认CI。

## 公开文件规则

- 保留源码、提示词、知识、合成数据、工程测试、可复用场景/工具及稳定架构说明。
- 评估文档只保留导航、架构选择、最终结果和汇总JSON。逐日报告与研究计划保留本地。
- 本地规划、原始岗位、密钥、运行库、索引和缓存由.gitignore排除。已被Git跟踪的文件不会因新增忽略规则自动移除；发布检查需识别此情况。
- 公开文档不能链接仅在本地存在的历史报告。新增文件后运行public:check检查候选发布文件与本地链接。

运行与评审记录追加保留，不覆盖旧失败；公开汇总需说明分母、未执行项、评审方式和适用边界，不公布凭证或具体费用。
